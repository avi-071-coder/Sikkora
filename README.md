## Key Features

| Feature | Description |
| :--- | :--- |
| **Interactive Monastic Cartography** | Custom-designed vector map of Sikkim segmented into West, South, East, and North regions, with filter hooks and hover-triggered details. |
| **360 Degree Virtual Tour Node Engine** | Immersive panoramic experiences with navigational nodes and interactive hotspots detailing architectural layers, shrines, and viewpoints. |
| **Historical Archive and Overlays** | A repository of royal charters, water prophecies, and decrees alongside interactive comparisons of 19th-century sketches and modern vistas. |
| **Pilgrimage Journey Planner** | A drag-and-drop pilgrimage stop builder with local storage state management and distance estimation metrics. |
| **Sacred Guide AI Chatbot** | A knowledge-trained conversational assistant responding to greetings, monastic history, visitor etiquette, and local circuits. |

## Getting Started

### Prerequisites

Ensure you have Node.js (v18 or higher) and npm installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/avi-071-coder/Sikkora.git
   cd Sikkora
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
